# 🎬 Smart Movie Explorer

## 📌 Project Description
Smart Movie Explorer is a web application that allows users to search, filter, and explore movies using real-time data from the OMDb API.

## 🚀 Features
- Search movies by title
- Filter movies by year/type
- Sort results alphabetically
- Responsive UI design
- Dynamic API data fetching

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🔗 API Used
https://www.omdbapi.com/

## 📂 Project Status
Initial setup completed. Features will be implemented in upcoming milestones.
